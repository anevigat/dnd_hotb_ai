# Resúmenes de sesión

Un archivo `session-NN-summary.md` por sesión jugada, generado por el skill `/session-end`. Son aptos para que los jugadores los relean (sin spoilers de `dm-only/`).

## Formato

```
# Sesión NN — <fecha>

## Resumen
(3-6 frases de lo que pasó)

## Eventos clave
- ...

## Estado al cierre
- Party: HP/condiciones relevantes
- Ganchos abiertos para la próxima sesión
```
