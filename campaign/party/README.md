# Party — personajes jugadores

Un archivo `.md` por personaje jugador, creado con ayuda del asistente a partir de las opciones en `../../knowledge/characters/`.

## Formato sugerido por personaje

```
# <Nombre del personaje> (jugador: <nombre del jugador>)

- **Clase**: 
- **Nivel/capítulo actual**: 
- **HP máximos**: 
- **Estadísticas/habilidades clave**: 
- **Equipo**: 
- **Rasgos/trasfondo**: 
- **Notas de progresión**: (qué ha ido desbloqueando capítulo a capítulo)
```

Los valores actuales en vivo (HP restantes, condiciones, posición) se llevan en `../state/current-session.md`, no aquí — este archivo es la ficha "de base".
