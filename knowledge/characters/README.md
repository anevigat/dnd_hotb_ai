# Personajes (héroes pregenerados)

Opciones oficiales de héroes del set: clases disponibles, stats base, cartas de equipo/habilidad iniciales, progresión por capítulo. Base para ayudar a los jugadores a crear/personalizar sus personajes en `campaign/party/`.

Alimentado por el skill `feeder`. Cada archivo debe registrarse en `../INDEX.md`.
