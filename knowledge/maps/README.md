# Mapas

Descripciones y referencias de mapas del set (aptas para consultar durante la partida: salas, conexiones, puntos de interés visibles). Si un mapa incluye elementos secretos (trampas ocultas, salas secretas, soluciones), esa parte va en `dm-only/`, no aquí.

Alimentado por el skill `feeder`. Cada archivo debe registrarse en `../INDEX.md`.
